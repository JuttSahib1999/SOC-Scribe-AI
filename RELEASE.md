# Release Notes

## Version 1.0.0 (MVP Release)
**Status:** Final Version (No future updates planned)

### Features Included:
* **Local AI Processing:** Full integration with Ollama for secure, offline log analysis.
* **Framework Mapping:** NIST IR and MITRE ATT&CK generation built into the LLM engine.
* **Multi-Format Export:** Fully functional export modules for Markdown, JSON, and DOCX.
* **Incident Database:** Local SQLite integration (`incidents.db`) to track report versions, history, and status.
* **Synthetic Data Module:** Quick-load functionality to generate realistic SOC scenarios for testing.
* **Strict AI Constraints:** Backend prompting engineered to prevent hallucination of IOCs and evidence.
